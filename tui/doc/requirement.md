# mdview-tui 要求仕様

両版に共通する決まり（対応拡張子、文字コード、Markdown の対応範囲、見出しのアンカー、リンクの扱いなど）は [`doc/common.md`](../../doc/common.md) を参照。

## 概要

ターミナル上で Markdown ファイルを整形表示する TUI ビューア `mdview-tui`。
1つの Markdown ファイル（または標準入力）を読み込み、見出し・表・コードブロックなどを装飾して表示する。
less/vim 風のキー操作でスクロール・検索・目次ジャンプ・リンク遷移ができ、表示中のファイルが更新されると自動で再読込する。

## 要求仕様

### 実行環境・実装

- 実装言語は Python（3.10 以上）、TUI フレームワークは Textual を用いる
- フロントマターの YAML の解釈には PyYAML を用いる
- 対象環境は Linux / WSL / macOS。Windows ネイティブ（Windows Terminal）はベストエフォート
- pip / uv でインストールでき、コマンド名は `mdview-tui` とする

### 入力

- 引数で指定した Markdown ファイル1つを表示する（複数ファイル・ディレクトリ指定は対象外）
- 引数が `-`、または引数なしで標準入力がパイプの場合は標準入力を読み込んで表示する
- 引数なしで標準入力が TTY の場合は使いかたを表示して終了する
- 文字コードは UTF-8 とする（BOM 付きも可）

### Markdown 対応範囲

- CommonMark 準拠の基本構文（見出し、段落、強調、リスト、引用、コード、リンク、水平線など）
- GFM 拡張: 表、タスクリスト、取り消し線、自動リンク
- コードブロックは言語指定に応じてシンタックスハイライトする
- 画像は描画せず、代替テキストとリンク先を表示する。リンク先は Markdown に書かれた通りの文字（日本語・空白を含む）で表示する
- 生 HTML は描画せずテキストとして表示する

### フロントマター

ファイル先頭の YAML 形式のフロントマターを本文と分けて解釈し、文書の情報として本文の先頭に表示する。どこまでをフロントマターとするかは、両版の共通仕様（[`doc/common.md`](../../doc/common.md)）に従う。

- 対象となる形式
  - 1行目が `---` だけの行（末尾の空白は可）で、その後に `---` または `...` だけの行が現れるまでの部分をフロントマターとする。閉じの行が無い場合はフロントマターとして扱わない
  - YAML 形式のみに対応する。TOML 形式（`+++`）などには対応しない
  - ファイルの途中にある `---` は、これまで通り水平線として扱う
  - フロントマター部分は本文として扱わない。水平線や見出しとして表示されたり、目次に現れたりしない
- 表示（本文の先頭に、次の順で表示する）
  - `title`: 題名として、H1 と同じ色の太字で表示する（H1 のような下線の罫線は付けない）
  - `author`・`date`: 題名の下に、薄い色で ` ・ ` でつないだ1行にまとめて表示する
    - `author` が配列の場合は「、」でつないで表示する
    - `date` は書かれた文字列をそのまま表示する（日付の書式は変換しない）。他の値も、`1.10` が `1.1` になるような変換はしない
  - 上記以外の項目: 点線の区切りの下に、キーと値の2列の一覧として、薄い色で書かれた順に表示する
    - 値が配列の場合は `, ` 区切りで、入れ子のオブジェクトの場合は `キー: 値` を `, ` で並べた1行で表示する
    - 長い値は端末幅で折り返して表示する
  - 最後に、本文との区切りとして幅いっぱいの罫線を引く
  - `title`・`author`・`date` のうち書かれていない項目は表示しない。点線の区切りは、題名または作成者・日付の行と、その他の項目の両方があるときだけ引く。表示する項目が1つも無い場合（空のフロントマターを含む）は何も表示しない
  - 本文に `title` と同じ文言の見出しがあっても、両方そのまま表示する
  - 目次には `title` を表示しない。目次はこれまで通り本文の見出しのみとする
  - 表示は本文の一部として扱い、検索の対象に含める
- YAML として解釈できない場合（構文の誤り、最上位がキーと値の形式でない場合）
  - 表示全体は壊さず、`フロントマターを解釈できませんでした: <理由>` と、フロントマターの元の文字列を本文の先頭に表示する。本文はフロントマター部分を除いて通常通り表示する
- 標準入力から読んだ場合も同じように扱う。自動再読込・手動再読込でフロントマターが変わった場合も表示に反映する

### 表示・操作

- 本文はスクロール表示し、端末幅に合わせて折り返す。端末リサイズに追従する
- 画面下部にステータスバー（ファイル名、現在位置の割合、検索状態など）を表示する
- テーマはダーク／ライトの2種類。既定はダークで、キー操作と `--theme` オプションで切り替えられる

### 検索・目次

- `/` でテキスト検索（大文字小文字を区別しない）。`n` / `N` で次／前の一致へ移動し、一致箇所をハイライトする
- 見出しから目次（TOC）を生成し、目次パネルから選択した見出しへジャンプできる

### リンク遷移・履歴

- 本文中のリンクを Tab / Shift+Tab で選択し、Enter で開く
- 相対パスの `.md` リンクはビューア内で開く（`#見出し` アンカー付きなら該当見出しへジャンプ）
- 同一ファイル内のアンカーリンク（`#...`）は該当見出しへジャンプする
- `http(s)://` などの外部リンクは OS 既定のブラウザで開く
- `.md` 以外のローカルファイルへのリンクは開かず、ステータスバーに「サポートしていないリンク: <リンク先>」と通知する。リンク先は Markdown に書かれた通りの文字で表示する
- 閲覧履歴を保持し、戻る／進むができる
- リンク先ファイルが存在しない場合はステータスバーにエラーを表示し、現在の表示を維持する

### 自動再読込

- 表示中のファイルが更新されたら自動で再読込し、可能な限りスクロール位置を維持する
- 表示中のファイルが削除された場合はステータスバーに通知し、最後の内容を表示し続ける
- 標準入力の表示時は自動再読込しない

### 外部エディタ起動

- `e` キーで表示中のファイルを `$VISUAL` → `$EDITOR` の順で決めたエディタで開く（未設定時は Linux/macOS で `vi`、Windows で `notepad`）
- エディタ終了後はビューアに復帰し、内容を再読込する
- 標準入力の表示時は無効（ステータスバーに通知）

### キーバインド（less/vim 風）

| キー | 動作 |
|---|---|
| `j` / `↓` | 1行下へ |
| `k` / `↑` | 1行上へ |
| `Space` / `f` / `PgDn` | 1画面下へ |
| `b` / `PgUp` | 1画面上へ |
| `d` / `u` | 半画面下／上へ |
| `g` / `Home` | 先頭へ |
| `G` / `End` | 末尾へ |
| `/` | 検索 |
| `n` / `N` | 次／前の一致へ |
| `t` | 目次パネルの表示切替 |
| `Tab` / `Shift+Tab` | 次／前のリンクを選択 |
| `Enter` | 選択中のリンクを開く |
| `Backspace` / `H` | 履歴を戻る |
| `L` | 履歴を進む |
| `e` | 外部エディタで開く |
| `r` | 手動再読込 |
| `T` | テーマ切替 |
| `?` | キーバインドのヘルプ表示 |
| `q` / `Ctrl+C` | 終了 |

### CLI

- `mdview-tui [OPTIONS] [FILE]`
- `--theme {dark,light}`: 起動時のテーマ（既定 `dark`）
- `--no-watch`: 自動再読込を無効にする
- `-h` / `--help`: ヘルプを表示して終了
- `-V` / `--version`: バージョンを表示して終了

### 終了コード

| コード | 意味 |
|---|---|
| 0 | 正常終了（`--help` / `--version` 含む） |
| 1 | ファイルが存在しない・読み込めない・UTF-8 として解釈できない |
| 2 | 引数・オプションの誤り、または入力なし（引数なしかつ標準入力が TTY） |
| 130 | TUI 起動前に Ctrl+C で中断された |

異常終了時は TUI を起動せず、標準エラー出力に `mdview-tui: <理由>` 形式でメッセージを出す。

### 対象外

- Markdown の編集機能（外部エディタに委ねる）
- 複数ファイルのタブ表示・ディレクトリブラウザ
- 画像・Mermaid 図の描画、数式のレンダリング
- 設定ファイル

## 使いかた

```console
# ファイルを表示
$ mdview-tui README.md

# ライトテーマで、自動再読込なしで表示
$ mdview-tui --theme light --no-watch doc/spec.md

# 標準入力から表示
$ cat CHANGELOG.md | mdview-tui
$ curl -s https://example.com/doc.md | mdview-tui -

# バージョン表示
$ mdview-tui --version
mdview-tui 0.1.0

# 存在しないファイル
$ mdview-tui nofile.md
mdview-tui: nofile.md: No such file or directory
$ echo $?
1

# 入力なし
$ mdview-tui
usage: mdview-tui [-h] [-V] [--theme {dark,light}] [--no-watch] [FILE]
mdview-tui: error: no input (specify FILE or pipe to stdin)
$ echo $?
2
```

### フロントマターの表示例

次の Markdown ファイルを表示した場合（幅 40）。

```markdown
---
title: 設計メモ
author: [山田 太郎, 佐藤 花子]
date: 2026-10-08
version: 1.10
tags: [md, viewer]
---

# はじめに
```

```
設計メモ
山田 太郎、佐藤 花子 ・ 2026-10-08
┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
version  1.10
tags     md, viewer
────────────────────────────────────────

はじめに
════════════════════════════════════════
```

目次には「はじめに」だけが表示される。
